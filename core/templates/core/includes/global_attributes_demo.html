Демонстрация глобальных атрибутов HTML

Открыть учебный пример

Глобальные атрибуты разрешено применять практически к любому HTML-элементу, хотя для некоторых элементов отдельные атрибуты могут не давать видимого эффекта.

id
Уникальный идентификатор элемента в пределах документа.
class
Одно или несколько имён классов для CSS и JavaScript.
style
Встроенные CSS-правила элемента.
title
Дополнительное описание элемента.
lang и dir
Язык содержимого и направление текста.
accesskey и tabindex
Клавиша быстрого доступа и положение элемента в порядке фокусировки.
hidden
Логический атрибут, скрывающий элемент.
contenteditable и spellcheck
Разрешение редактирования содержимого и проверка правописания.
translate
Указывает, следует ли переводить содержимое элемента.
data-*
Пользовательские данные, доступные через свойство dataset.
draggable
Указывает, можно ли перетаскивать элемент.
itemscope, itemtype, itemprop, itemid, itemref
Глобальные атрибуты микроданных.
onclick
Пример глобального атрибута обработчика события.

Листинг

<div
    id="global-attribute-example"
    class="global-attribute-demo"
    style="border: 1px solid #777"
    title="Описание элемента"
    lang="ru"
    dir="ltr"
    tabindex="0"
    accesskey="g"
    contenteditable="true"
    spellcheck="true"
    translate="no"
    draggable="true"
    data-demo-purpose="global-attributes"
    itemscope
    itemtype="https://schema.org/Thing"
    itemid="#global-attribute-example"
    itemref="global-attribute-extra"
>Содержимое</div>

<p hidden>Скрытый элемент</p>

Примечание: атрибут dropzone присутствует в лекции, но исключён из современного стандарта HTML и поэтому не используется в рабочей разметке.
